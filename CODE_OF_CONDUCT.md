# Community code of conduct

Be respectful, constructive and patient. Discuss ideas and code without
attacking people. Welcome contributors with different backgrounds, experience
levels and languages.

Harassment, discrimination, threats, sexualized content, doxxing and deliberate
disclosure of someone else's private information are not acceptable. Do not
post credentials or personal server details.

Maintainers may edit or remove harmful content, close disruptive discussions,
or restrict participation. Decisions should be proportionate to the conduct
and explained where doing so does not expose private information.

To report a concern privately, use the maintainer contact listed on the
[official support page](https://serverkiln.littleor.cn/en/support/). Include links
and enough context to investigate; do not publish personal details in an issue.
