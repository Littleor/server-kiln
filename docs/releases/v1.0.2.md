ServerKiln's first open-source macOS release: GPU fleet status in your menu bar,
with per-card metrics, task details, local history and training activity alerts.

## Download

| File | Use |
| --- | --- |
| `ServerKiln-1.0.2-universal.dmg` | Recommended: open and drag ServerKiln to Applications |
| `ServerKiln-1.0.2-universal.zip` | ZIP containing the same app |
| `SHA256SUMS` | SHA-256 checksums for both downloads |

**macOS 14+ · Apple Silicon and Intel · Developer ID signed · Apple notarized**

## Highlights

- Native SwiftUI fleet overview, configurable two-row menu bar and dark/light modes.
- NVIDIA GPU utilization, VRAM, temperature and power; CPU-only servers supported.
- SSH config import, adaptive refresh, running tasks and local resource history.
- Debounced busy/idle notifications and optional connection alerts.
- English and Simplified Chinese included in the app bundle.
- Optional iCloud relay and dedicated-key setup for the separately distributed
  iPhone companion, available in the official signed Mac build.
- Mac source under MIT, with build instructions, CI and contributor documentation.

The source release includes Mac functionality and its required shared code.
The iPhone app and widgets are not included. Ad-hoc builds cannot access the
official iCloud container. Updates are installed manually.
