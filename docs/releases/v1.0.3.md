## ServerKiln 1.0.3

- Check GitHub Releases from Settings → General, with optional daily background checks.
- Updates require your confirmation. Downloads are verified before installation; the app reopens afterwards.
- Background update reminders appear in the menu bar panel and Notification Center.
- Improved CPU and memory process rankings, expandable details, and command/PID copying.
- Improved iPhone relay compatibility and notification subscription handling.
- Release validation checks the actual app inside the DMG and appcast version/build consistency.
- Failed releases preserve previous artifacts.

**macOS 14+ · Universal (Apple Silicon + Intel) · Developer ID signed · Apple notarized**

Install this version manually once to enable in-app updates. Subsequent releases can be installed after confirming the update prompt.

Downloads: DMG (recommended), ZIP, appcast.xml (updater feed), SHA256SUMS.
