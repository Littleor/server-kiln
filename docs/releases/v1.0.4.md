## ServerKiln 1.0.4

- iPhone notifications return to the original, unfiltered iCloud subscriptions used before per-server mute (with the iPhone app 1.0.4).
- Servers muted on the iPhone are now skipped by the Mac before it sends an event. Update the Mac for iPhone per-server mute to take effect.
- Removes temporary notification diagnostics.

**macOS 14+ · Universal (Apple Silicon + Intel) · Developer ID signed · Apple notarized**

Install from the update prompt in ServerKiln 1.0.3, or download the DMG below.

Downloads: DMG (recommended), ZIP, appcast.xml (updater feed), SHA256SUMS.

## 简体中文

- iPhone 通知恢复为加入按服务器静音之前、不带过滤条件的 iCloud 订阅（配合 iPhone 1.0.4）。
- 在 iPhone 上静音的服务器，现在由 Mac 在发送前直接跳过；需要更新 Mac 才能使 iPhone 端的服务器静音生效。
- 移除临时的通知诊断功能。

macOS 14 及以上，兼容 Apple Silicon 和 Intel。可在 1.0.3 的更新提示中确认安装，或下载下方 DMG。

下载后运行 shasum -a 256 -c SHA256SUMS 校验文件。
