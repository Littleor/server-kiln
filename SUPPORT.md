# Getting help

Start with [getting started](docs/getting-started.md) and
[troubleshooting](docs/troubleshooting.md). For reproducible bugs and feature
requests, use the [issue templates](https://github.com/Littleor/server-kiln/issues/new/choose).
English and Chinese are welcome.

Include the app version, installation source, macOS version, processor type and
minimal reproduction steps. Remove real server addresses, usernames, private
keys and sensitive command arguments from screenshots and logs.

Questions about the separately distributed iPhone app can go through the
[official support page](https://serverkiln.littleor.cn/en/support/).
Security issues follow [SECURITY.md](SECURITY.md).
