# Security policy

Security fixes target the latest stable macOS release. Upgrade before reporting
a problem that may already be fixed. This project does not promise a response
time or a paid support service.

## Report privately

Use [GitHub private vulnerability reporting](https://github.com/Littleor/server-kiln/security/advisories/new)
when available. If it is unavailable, contact the maintainer through the
[official support page](https://serverkiln.littleor.cn/en/support/) and request a
private channel before sending exploit details. Do not open a public issue with
credentials, a working exploit against a live system or private server data.

Include the app version, macOS version, affected component, a minimal
reproduction using a disposable host, and expected versus observed behavior.
Please allow time to investigate and prepare a fix before public disclosure.

See [the security and privacy model](docs/security-and-privacy.md) for SSH access,
companion-key restrictions and storage boundaries.
